# 📎 ClippyPlace

Un lienzo colaborativo en tiempo real al estilo r/place, integrado para **AuraOS** y la web. 🎨✨

## 🚀 Características
- 🖼️ **Lienzo en Tiempo Real:** Dibuja píxeles y mira los cambios de otros usuarios al instante vía Supabase.
- ⏱️ **Sistema de Cooldown:** Control de spam para mantener la experiencia justa.
- 🎨 **Paleta de Colores:** Selección rápida de colores para tus creaciones.
- 🌐 **Integrado con Chronioñ Browser / AuraOS.**

## 🛠️ Tecnologías
- **HTML5 Canvas & JavaScript**
- **Supabase Realtime (PostgreSQL WebSockets)**
- **GitHub Pages**
